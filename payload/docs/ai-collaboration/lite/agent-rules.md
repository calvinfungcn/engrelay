## EngRelay Lite workflow (conditional)

The installed WorkflowProfile is lite. Read the WorkflowMode declaration above.
In optional mode activate only when this task explicitly selects EngRelay or
EngRelay-Lite; default uses Lite unless another controller is selected; disabled
requires an explicit request to re-enable first. Discovery and historical state
do not select a workflow. Use one primary controller per task.

When selected, read docs/engrelay-lite/RULES.md, docs/engrelay-lite.config.md and
the current approved task. Resume from that task's .ai/engrelay-lite/ handoff and
named evidence. Read actual source and applicable module instructions as needed.
Maintain real boundaries, cumulative reviews and independent M/H checks under
those rules. No Full handbook or dedicated Skill is required.

Full-only ai-collaboration and ai-collab-* entries do not match Lite: explain the
mismatch and point to docs/engrelay-lite/RULES.md. Do not create Full state or
switch profiles. Preserve historical Full state and project text outside this block.
Inactive tasks follow their selected controller and project constraints.
