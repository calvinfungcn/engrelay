# Handoff Review Prompt Example

This document is a non-authoritative example for reviewing handoff scope,
routing, state, and evidence. It contains no task acceptance or business
history.

```text
Please independently review the proposed handoff change.

Inspect only the named requirements, source files, tests, and evidence. Confirm
that routing, status, role ownership, review limits, and verification claims
remain coherent. Report high-confidence findings with file and line references,
impact, and the smallest useful correction. Separate suggestions from findings
and list unverified areas.
```
