# Independent Review Prompt Example

This document is a non-authoritative example for reviewing a proposed
collaboration-learning change. It contains no task acceptance or business
history.

```text
Please independently review the proposed collaboration-learning change.

Use read-only inspection. Check the current diff, requirements, tests, and
evidence that are explicitly in scope. Report only high-confidence findings
with file and line references, impact, and the smallest useful correction.
Separate non-blocking suggestions from findings and state what was not
verified.
```
