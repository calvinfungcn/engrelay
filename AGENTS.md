# EngRelay package maintenance

Read README.md and CONTRIBUTING.md before changing this package. The product
contracts live under payload/docs/ai-collaboration/. Installation does not activate
the role workflow; use one primary controller selected for the current task.

Keep canonical installed paths, managed markers, Skill names, role anchors,
machine fields, ownership protection, and documented review independence compatible.
Do not use real projects as regression fixtures or install the package into itself.
Use validated disposable directories. Do not change Git, global settings, or
perform real deployments without the applicable user request.

Keep private runtime state, credentials, tool caches, original project snapshots,
and raw installation backups out of Git. Never claim that a structure check
proves business acceptance or host loading. Report actual checks and limits.

Change both README language editions together when public behavior changes. Edit
canonical Skills under payload/, never generated host copies. Regenerate the
snapshot after package byte changes; only a complete matching inventory is a
valid installation source.

Original EngRelay material uses the MIT License. Preserve third-party notices
and source-audit limits; publication and real deployments require the applicable
user request. This file does not authorize external operations by itself.
